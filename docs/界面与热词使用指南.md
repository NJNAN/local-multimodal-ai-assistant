# 界面与热词使用指南

双击项目根目录的 `启动助手.bat` 启动新版。已有窗口需要关闭后重新启动。

## 聊天

用户消息与头像在右侧，AI 回复与头像在左侧。支持流式回复、选中文本和复制回答。
Enter 发送，Shift+Enter 换行，Esc 停止生成和播报。手动滚动查看旧消息时，流式回复不会持续拉回底部。
参考资料显示在对应回答下面。设备状态、手势动作和推理指标不会插入对话。
详细后台日志保存在 `outputs/logs/multimodal_assistant.log`；推理监控和对话导出仍保留。

左侧操作区可滚动，包含上传图片、摄像头开关、使用摄像头画面、分析画面、分析手势、实时手势控制、导入资料、暂停/恢复聆听和自动播报。热词与监控入口固定在左侧底部。右上方保留模式选择、恢复自动路由、新对话与导出对话。

## 语音响应

启动后先显示“正在准备语音识别”，SenseVoice 预热完成后切换为已开启。预热只在启动时进行，后续识别复用同一模型。
自动断句默认等待约 450ms 静音。背景声一直被判为语音时，约 8 秒会强制提交一段，防止持续录制几十秒。前滚和尾音保留可能使实际送入识别的音频略长于 8 秒。长时间连续讲话会分成多段。
说完后可点击输入区的“立即识别”，无需等待静音；低于 0.5 秒的碎片仍会过滤。
采集与识别分开运行，识别时继续读取麦克风，等待识别的队列最多两段；暂停监听或开始播报会丢弃过期结果。

默认“快速音色（离线）”使用 Windows 已安装的中文音色，复用隐藏的系统语音进程，不依赖联网或新增 Python 库。不修改系统注册表。未安装中文音色时回退在线语音。
在左侧语音偏好中可切换到“自然音色（联网）”，继续使用 Edge TTS。在线合成有单次总超时保护，网络不畅会提示失败。
回答生成时逐句播报，不再等全文完成；播放当前句时会预合成下一句。播报期间继续读麦克风但丢弃声音，避免助手将自己的回答当作新提问；结束后自动恢复此前的聆听状态。可使用停止按钮或 Esc 中断播报。

相关环境变量：`MMAI_SILENCE_MS`、`MMAI_MAX_SPEECH_MS`、`MMAI_TTS_BACKEND`（auto/windows/online）、`MMAI_TTS_TIMEOUT`。

## 自定义专业词

1. 点击左下方“自定义语音热词”。
2. 点击“添加热词”，填写标准词和常见误识别词。例如标准词 `通义千问`、误识别词 `同义千问`。
3. 多个误识别词用中文或英文逗号分隔。双击已有单元格可修改，选中行后可删除。
4. 点击“保存并应用”。立即更新当前识别引擎，下次启动自动读取 `data/hotwords.json`。
5. 取消勾选“启用热词纠正”并保存，可以保留词表并暂停纠正。

使用 SenseVoice 转写后的词表纠正：先清理识别标记，再纠正专业词，随后写识别记录并提交给 AI。仅匹配明确列出的写法，不根据相似发音自动猜词。中文别名匹配采用最长词优先；英文词处理大小写并防止误改其他英文单词。
只添加标准词时会统一该词的英文大小写；要纠正中文错字，应同时填写实际出现的误识别写法。一个误识别词对应多个标准词时会提示冲突，不覆盖已有配置。

## 摄像头

“关闭摄像头”在采集线程释放真实设备并清空最近帧缓冲，同时清除预览与实时手势状态；再次开启会重新打开设备。关闭后仍可使用已上传图片，不能继续询问已清除的摄像头画面。
“使用摄像头画面”用于从图片切回摄像头来源，与设备开关是两个独立功能。
“分析画面”分析当前上传图片或已开启的摄像头帧。

## 验证与预览

运行 `python -m pytest` 验证交互与后台逻辑，`python main.py --smoke-test` 检查实际组件启动和退出。
`python scripts/17_preview_chat_ui.py` 可在不加载模型或启用设备的情况下渲染欢迎页、聊天页、小窗口和热词编辑器。其截图中的对话为展示布局的示例内容。

`python scripts/18_check_voice_latency.py --with-model --with-online` 回放最近三段已有录音并测量断句、真实 ASR 与两种 TTS 后端；不播放声音。结果写入 `outputs/voice_latency_check/report.json`，其中识别结果仅保留字符数。

2026-10-08 本机实测：同一组 8 字和 22 字测试文字，预热后的 Windows 合成为 0.0924s / 0.0190s，后台音色准备为 0.3451s；在线首句为 6.6746s，另一句遇到网络超时。三段 8.01 秒录音的真实 ASR 为 0.1421～0.1542s。以上是分环节耗时，不代表说完到听见整段答案的总时间。

摄像头释放、清空和重新开启有设备替身与真实 Qt 按钮回路的回归测试。当前执行环境未能打开摄像头 0，因此实体摄像头开关仍需在有可用摄像头的机器上确认。
